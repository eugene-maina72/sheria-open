# Release checklist

## Legal corpus

- [ ] All documents have official source URLs.
- [ ] Status and effective dates have been verified.
- [ ] Checksums and parser versions are recorded.
- [ ] Changed or removed sources have been reviewed.

## Quality

- [ ] Retrieval evaluation passes.
- [ ] Citation validation passes.
- [ ] No invented instruments or provisions appear in the benchmark.
- [ ] High-risk scenarios escalate correctly.
- [ ] English and Kiswahili samples have been reviewed where applicable.

## Security and privacy

- [ ] Dependency and container scans are reviewed.
- [ ] Secrets are not present in the repository or image.
- [ ] Ollama is not publicly exposed.
- [ ] Logging and retention settings match policy.
- [ ] Backups and rollback have been tested.

## Open-source operations

- [ ] Changelog is updated.
- [ ] Third-party notices are updated.
- [ ] Licence text is complete.
- [ ] Documentation matches deployed behaviour.
- [ ] Known limitations are published.
