- **Creative Commons Attribution-ShareAlike 4.0 International**

## Official legal material

Legislation, Bills, judgments, Gazette notices and other official publications are not relicensed by SheriaOpen. Preserve:

- official title and citation;
- issuing institution;
- source URL;
- publication, assent, commencement and effective dates where relevant;
- retrieval and verification dates;
- amendment, repeal and version information; and
- any source-specific attribution or reuse terms.

## Third-party dependencies

Python packages, JavaScript packages, containers and other dependencies retain their original licences. Generate and update a dependency notice or software bill of materials before each public release.

## Language-model and embedding weights
